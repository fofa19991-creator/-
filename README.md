# المساعد الذكي للمعلم (AI Teacher Assistant)

منصة احترافية موجهة للمعلمين والمعلمات في المملكة العربية السعودية لمساعدتهم على إعداد الدروس، الاختبارات، أوراق العمل، والخطط الدراسية باستخدام الذكاء الاصطناعي (Gemini API).

## المميزات
- تحضير درس متكامل وفق معايير وزارة التعليم السعودية.
- إنشاء اختبارات متنوعة (اختيار من متعدد، صح وخطأ، مقالي) مع نموذج الإجابة.
- المساعد الذكي (Chatbot) للمحادثة الفورية وتنسيق الملفات.
- دعم الوضع الليلي/النهاري واللغة العربية بالكامل (RTL).
- تصميم عصري وسلس باستعمال Flutter و Clean Architecture و Riverpod.

## التقنيات المستخدمة
- **Flutter**: بناء واجهات التطبيق وموقع الويب.
- **Firebase**: إدارة الحسابات، Firestore، و Cloud Storage.
- **Gemini API**: نموذج الذكاء الاصطناعي لتوليد المحتوى التعليمي.
- **Riverpod**: إدارة حالة التطبيق.
